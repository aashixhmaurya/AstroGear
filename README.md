# AstroGear

AstroGear is a simple browser based gear simulation project which i made while learning.  
idea was to understand how gears actually work and how their speed and relation changes.

in starting it was very basic and confusing but slowly i improved things step by step.

## What this project does

you can create gears and connect them with each other  
see how they rotate and how rpm changes  
basic simulation is there to understand relation between gears  

## Features

- gear simulation system  
- auto positioning of gears  
- basic rpm and relation calculation  
- simple control panel ui  
- info labels showing main parameters  

## Tech Used

- HTML  
- CSS  
- JavaScript
